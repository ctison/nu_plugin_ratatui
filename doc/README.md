# nu_plugin_tui documentation

`nu_plugin_tui` lets Nushell scripts describe and run terminal user interfaces with records and closures.

## Guides

- [Getting started](getting-started.md) covers building, running, and installing the plugin.
- [Applications and events](applications-and-events.md) explains state, reactive views, event records, and handler results.
- [Widget reference](widgets.md) lists every widget, layout constraint, and style field.
- [Development](development.md) covers repository layout and local checks.

For a complete runnable application, see [`examples/counter.nu`](../examples/counter.nu).
